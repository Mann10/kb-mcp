## Decisions Made

- Fixed-width `rich.console.Console(width=200)` for the list table: the default auto-width (80 when piped or under CliRunner capture) truncated `prefix...suffix` and timestamps, breaking prefix usability in exactly the piped/CI contexts operators use. Wide width renders full values everywhere (see deviation 1).
- Rotate success output uses three lines (`Rotated <display> (user).` + `New token for 'user': <raw>` + one-time wording) because `rotate_by_prefix` returns only the new entry — the old display is unrecoverable post-mutation, so a literal old→new arrow would require a pre-rotate lookup the store deliberately does not expose.
- Kept the `isolated_cli_env` fixture local to `tests/test_cli.py` instead of extending `tests/conftest.py` — no other module needs it and conftest stays untouched.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Rich table truncated display strings under narrow consoles**
- **Found during:** task 3 (CLI proofs)
- **Issue:** `Console().print(table)` auto-detects width 80 when piped or under CliRunner capture, cropping `prefix...suffix` to `prefix…` (with ellipsis char) and slicing timestamps — the `test_list_table_and_json_hide_secrets` assertion for literal `...` failed, and a manual smoke run showed the same truncation in piped output. Truncated displays break prefix copy-paste, the CLI's core identity mechanism.
- **Fix:** `Console(width=200).print(table)` so full display strings and ISO timestamps render intact in terminals, pipes, and test capture.
- **Files modified:** src/kb_mcp/cli.py
